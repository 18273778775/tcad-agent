# TCAD Agent CLI 0.4.0

CLI 提供图纸基础能力，agent 组合这些能力完成用户任务。Excel 计算和房间建模保留为验收案例，不再列为缺少通用业务命令的不足。

## 相关图纸只准备一次

`workset` 将明确选中的图幅或多个 bbox 保存为来源可核验的子图。查询、索引、测量、面积、标注关联、轴网、渲染及导出统一支持 `--workset`；后续仅解码子图，并校验原图和子图摘要。单页可继续框选；相关选页可一次生成 SVG、PNG、清单与 HTML。原图仍可直接调用，单次只读请求内也复用相同文档。

实图总计 30,433 个原生实体：基础单页工作集保留 369 个，两页相关工作集保留 888 个。单页准备约 34 秒；同输入、同范围、同工作负载下，监督进程的线段测量约 15.08 → 4.85 秒，SVG 约 22.79 → 12.35 秒。后续三个分析命令解析原整图次数为零，仍会解析子图。这是本机单次实测，不是任意图纸的速度保证。[完整口径](../large-drawing-performance.md)。

## 预览显示与证据

修复底层 SVG 后端的图片绘制空实现；本地图片解码后内嵌 PNG，支持裁切、绘制顺序、PNG 输出和分图缩略图。显式资源/字体目录、字体映射和累计资源预算可补齐真实可用资源，不自动下载外链。

`preview_quality` 区分内容缺失与外观替代，`--strict` 对不完整选区返回 `PREVIEW_INCOMPLETE` 且不发布/覆盖输出。缺少原始字体、bigfont 组合、xref 等仍需要核对，不能靠生成占位图宣称恢复。已有真实柱图重绘会报告字体外观替代。

## 标注和直轴关系

原生 MLEADER 与明确指定图层的多段线引线可参与关联，保留锚点、引线端点、竞争候选、距离差和歧义。新增旋转 LINE、共线开多段线直轴、真实方向交点与保存后的空间查询；弧轴和弯折路径返回不支持诊断。

实图柱图复验为 10 个唯一柱标注关联、6 竖轴、4 横轴、20 个轴号和 24 个交点。几何关系不是构件语义或计价规则，解释由 agent 结合图名、文字及预览完成。

调用与基础能力见 [agent-basis.md](../agent-basis.md)，剩余范围见 [current-limitations.md](../current-limitations.md)。

本地完整回归：454 项通过、1 项可选隔离安装测试跳过、9 subtests 通过；ruff 检查通过。测试覆盖实际 PNG 像素、资源限制、严格模式不发布、范围交集/并集、原图零重复解析、引线歧义、旋转轴及原有图纸事务与房间验收流程。

可选发行测试另行执行：11 项通过，实际构建 wheel、在源码目录之外用 uv 隔离安装，并运行版本、能力、创建和查询命令。测试读取协议输出时显式使用 UTF-8，兼容 Windows 的系统区域设置。
