# TCAD Agent CLI 0.3.1

Release date: 2026-10-23. Author: LiTao. License: Apache-2.0.

The Windows 3.12 CI failure occurred after unit tests and wheel creation passed.
The Python/pip installer chose `py -3`, which resolved to the runner's unrelated
global Python 3.15. Shapely 2.1.2 then attempted a source build instead of using
the available 3.12 binary distribution. This release fixes interpreter selection
instead of suppressing the failing installation check.

The installer resolves one absolute Python executable before creating its
virtual environment. The current PATH interpreter takes priority over the
global launcher; `-Python` allows explicit selection. All Windows matrix
versions exercise the real pip installer and verify the installed interpreter.
The CI matrix covers Python 3.11, 3.12 and 3.13. Installing on newer interpreter
versions remains dependent on native dependency support; uv's default 3.12
installation remains the recommended reproducible route.

For the common split-then-filter workflow, `render` can recover a split DXF's
own frame from its neighboring verified manifest. It checks the exported DXF
identity, keeps its native entity identities and does not reuse source drawing
handles. An explicit bbox remains authoritative. A standalone copied file with
no verified manifest keeps ordinary DXF rendering semantics; inspect its
selection diagnostics or supply a bbox rather than assuming a detected frame.

```powershell
tcad split project.dwg --output-dir sheets
tcad render 'sheets/column-plan.dxf' --layers AXES AXIS_LABELS COLUMNS COLUMN_LABELS --output columns.svg
```

Layer names above are illustrative. Query the actual file's layers and use
resolved leaf-layer selections, including layer-0 inheritance inside blocks.
The existing converter, external-image, font, 2D geometry and resource-budget
limitations continue to apply. Project-specific private drawings are not
included in the public source or release archives.

Local validation: 376 tests and 9 subtests passed; one optional clean-tool
installation test was skipped by default. The Windows pip path was also tested
with the complete 0.3.1 wheel and dependencies on CPython 3.12.13, and the
installed command reported version 0.3.1 and successful capabilities.
