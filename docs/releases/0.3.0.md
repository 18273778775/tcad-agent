# TCAD Agent CLI 0.3.0

Release date: 2026-10-22. Author: LiTao. Project license: Apache-2.0.

This release adds verified sheet delivery, selective previews and explicit planar
analysis to the bounded JSON CLI. The protocol remains version 1.0; use
`tcad capabilities` and `tcad schema request` to discover the installed contract.

## Sheet delivery and previews

- `sheets` discovers rectangular frames and records title evidence. Configure
  frame block/aspect-ratio hints, title/number layers, named regex captures and
  selective name overrides. Main titles, subtitles, building/elevation/kind
  evidence and ambiguity remain inspectable.
- `split` produces independent DXFs, self-contained path SVGs, verified PNG
  thumbnails, a manifest and an offline HTML gallery. Every serialized DXF is
  reopened; selected geometry, referenced blocks, resources, image definitions,
  presentation headers, artifact hashes and source coverage are checked before
  publication. Unassigned native entities receive a separate remainder artifact.
- Preserve complete font charset/pitch flags, default resource values, distinct
  IMAGEDEF identities and valid image reactor links. SVG/PNG previews retain
  explicit diagnostics for unavailable external images, glyphs and unsupported
  content.
- `render --layers ... --exclude-layers ...` filters nested block leaf layers
  with layer-0 inheritance. Keep axes, axis labels, columns and column labels in
  one reusable preview. Use a source-bound `--manifest` with `--sheet` to avoid
  manually moving handle lists through the agent context.
- `render --sheet all --output-dir ...` redraws a full sheet set from one parsed
  source. SVG/PNG output and bounded label/area/axis overlays are available.
  PNG rasterization uses resvg code rather than browser screenshots.

See [sheet workflow](../sheet-workflow.md) for exact flags and verification scope.

## Planar analysis and spatial evidence

- `area --mode union|sum|overlap` reports explicit union, raw sum and multiplicity
  excess, plus duplicate/contained/overlap evidence and layer/block/sheet groups.
  Invalid boundaries are rejected by default. Optional repair and precision-grid
  snapping are explicit and reported. Curved boundaries carry approximation
  metadata; no certified area-error bound is claimed.
- `measure` rejects invalid self-intersecting areas and adds supported planar
  HATCH/ELLIPSE/SPLINE boundary measurements. It remains a per-entity sum;
  use `area` for Boolean union and inspect completeness flags.
- `associate` returns geometric label-to-boundary pairs with unmatched and
  ambiguous evidence. `axes` extracts orthogonal line grids and can query a
  source-bound saved grid by point or rectangle. Neither command infers
  engineering meaning from ambiguous text.
- `index` builds a bounded persistent SQLite R-tree snapshot. Native INSERT
  world bounds participate in rectangle filtering. `query --text-scope
  layout|block|all` exposes instance-aware block annotations; shared selectors
  support sheet/rectangle regions and source revision checks.

## Agent and dependency contract

Default stdout stays bounded to 32 KiB. Complete evidence remains in explicit
artifacts; pagination, omission flags, structured errors and atomic publication
remain part of the contract. `split` defaults to an 1800-second supervised
deadline because complete export/readback can be substantial; other ordinary
commands default to 60 seconds. `--cache-dir` isolates persistent caches.

New pinned dependencies are Shapely 2.1.2 and resvg_py 0.5.0. Shapely supplies
GEOS-backed planar operations; resvg_py supplies static SVG rasterization.
Their upstream and bundled dependency licenses remain separate from this
project's license; see [third-party notices](../../THIRD_PARTY_NOTICES.md).

## Validation and boundaries

Validation includes 362 passing tests, 9 passing subtests and one opt-in skip;
11 isolated installation checks also passed. An anonymized real-drawing
acceptance case produced 52 reopened DXFs, 52 parsed SVGs and 52 verified,
nonblank PNGs. All 30,433 normalized source entities were accounted for,
including 25 in the remainder. All 52 title content sets matched a separately
recorded baseline; two composite titles differed only in ordering. These are
case-specific checks, not a guarantee for arbitrary CAD inputs. Private drawings
and their identifying contents are not distributed with this release.

DWG reading still depends on an external converter and its warnings. Output
editing remains DXF. Verification is relative to normalized DXF geometry and
selected resources, not a lossless DWG/application-object-graph proof. Arbitrary
rotated frames, paper-space viewport reconstruction, PDF output, general
component recognition and automatic engineering quantity certification are
outside this release. Units require explicit evidence; curve approximation,
unknown/partial bounds, missing fonts and incomplete selections must be checked.
