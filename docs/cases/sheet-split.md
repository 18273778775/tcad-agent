# 真实结构图：分图、命名和按层预览

这次验收使用一份真实结构施工图。原 DWG 约 4.97 MB，转换后的 DXF 约 32.82 MB，
模型空间有 30,433 个原生实体。公开图片只保留必要的图名和柱图区域，不包含源 CAD、
完整分图文件、项目图签或盖章。下文的数量来自实际保存的验收清单。

## 从一张总图得到 52 组文件

程序识别出 52 个图框，分别生成独立 DXF、SVG 和 PNG，并提供 `manifest.json`
与离线 HTML。图名取自框内文字；复合图幅保留主标题和子标题。本例有 13 页含多个
主视图标题。图名内容集合逐页核对为 52/52 一致，其中 2 页复合标题的排列顺序不同。
这次结果不代表标题识别已适用于任意图纸。

![52 个真实图框的位置示意及 3 组实际输出文件名](../assets/split-case.png)

上图左侧根据清单中的边界坐标绘制，表示图框位置和比例，不是 CAD 截图。
右侧列出真实输出名称，例如：

```text
结施-09_4#楼 负一层结构平面图.dxf
结施-09_4#楼 负一层结构平面图.svg
结施-09_4#楼 负一层结构平面图.png
```

52 份 DXF 均已实际回读，并比较所选原生实体、引用块、资源和约定的显示参数。
52 份 SVG 均通过 XML、有效范围、非空路径和外链检查；52 份 PNG 核对了格式、
尺寸和文件摘要。25 个框外实体另存至 `__tcad_unassigned__.dxf`，仍需人工判断归属。

这些检查以转换后的 DXF 为参考。转换器曾报告未知对象和不稳定 MATERIAL，
不能据此声称原 DWG 无损。整批预览另有 104 次外链图片缺失占位，20 页有专用字形
缺失警告；文件生成成功不等于原 CAD 的全部显示内容都已复现。

## 已拆分的单页，只看柱和轴网

从 `sheet-041` 的独立 DXF 中，保留以下 7 个实际图层，再框选其中的柱平面区域：

```text
Axis_2
01_02_PLAN$0$A_N_AXIS
01_02_PLAN$0$A_N_AXIS_TEXT
COLU
COLU_HATCH
COLU_DIM
TEXT
```

![从已拆分单页生成的柱图：10 个柱轮廓及编号、6 条竖轴、4 条横轴和 20 个轴号](../assets/split-layer-preview.png)

[打开原始矢量 SVG，放大查看](../assets/split-layer-preview.svg)。这是 CLI 直接生成的
预览，PNG 与 SVG 均原样复制自实际验收成果，未重绘或补写图纸内容。这个区域保留了
10 个柱轮廓、10 个 KZ/LZ 编号、6 条竖轴、4 条横轴及 20 个轴号。轴网分析得到
24 个有限线段交点；柱编号与柱轮廓的几何关联为 10/10 唯一匹配。本区域的专用视图
没有缺字或跳过实体诊断，这不消除整批图纸中的显示警告。

以上为 0.3.1 保存的案例。0.4.0 的质量检查进一步报告该区域缺少原始字体及 bigfont
组合信息：内容仍可绘制，外观标记为 degraded；严格模式会拒绝把替代字体当作完整
复现。重新核对的柱关联与轴网数量不变。缺失资源须由调用方提供。

0.3.1 中，`render` 会核对独立 DXF 和相邻清单的文件 SHA，沿用已验证图框；
显式 `--bbox` 可进一步选取局部区域。本次也用原总图的相同范围和图层生成对照，
两路 SVG 字节一致。原总图、独立 DXF 和清单均未改变。

图纸 `INSUNITS=0`。物理单位必须另行确认，不能从这张预览量尺，也不能仅凭柱的
平面轮廓推断高度或体积。此处验证的是分图、按层显示和局部几何关联。

完整用法见[分图与分层预览文档](../sheet-workflow.md)。
