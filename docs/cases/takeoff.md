# 从基础平面到承台体积表

这个案例处理一份实际结构施工图中的 CT2—CT5 承台。CLI 查询基础平面的标签、命名块和尺寸标注；案例计算脚本据此整理尺寸、计算体积并生成 Excel。两种计数分别核对，得到 CT2 / CT3 / CT4 / CT5 共 13 / 11 / 3 / 1 个。

![承台工作簿汇总页数据摘录](../assets/takeoff-case.png)

图片从已保存工作簿的单元格值确定性排版，保留了计算式和缓存结果，移除了工程名称等身份信息。它不是 Microsoft Excel 窗口截图。源图、完整工作簿和私有项目资料没有随仓库公开。

## 本次计算结果

尺寸单位为 mm，体积单位为 m³；尺寸依据图中标注及单位说明，不直接用显示图形的长度代替标注值。

| 名称 | 数量 | 单个体积计算式 | 单个体积 | 合计体积 |
| --- | ---: | --- | ---: | ---: |
| CT2 | 13 | 1800×800×900÷10⁹ | 1.296 | 16.848 |
| CT3 | 11 | [(1546+1892)×300÷2+(1892+346)×1339÷2]×900÷10⁹ | 1.8126369 | 19.9390059 |
| CT4 | 3 | 1800×1800×900÷10⁹ | 2.916 | 8.748 |
| CT5 | 1 | 2298×2298×1000÷10⁹ | 5.280804 | 5.280804 |
| **合计** | **28** | **包含 CT3 构型条件量** | | **50.8158099** |

**50.8158099 m³ 是按以下条件计算的试算量，不是已经确认的工程结算量。**

- **CT2 有图纸矛盾。** 基础平面为 1800×800×900 mm，详图长度为 2000 mm。本次按用户选定的基础平面计算。若改用详图，CT2 合计增加 1.872 m³；这个选择没有消除设计矛盾。
- **CT3 含待复核的构型假设。** 按图示三向对称截角构型重建，顶边 346 mm 由 2×173 推导，不是独立直接标注。1339 mm 来自 346+693+300。构型仍须复核。
- **CT5 采用整数标注。** 2298=300+849+849+300 mm；CAD 几何中对应分段约为 848.528137 mm。本次使用标注值，保留了舍入差异。
- **范围是承台本体毛体积。** 不含 100 mm C15 垫层、桩、柱及基础梁，未扣钢筋及嵌入桩头，也未套用特定计价规范的扣减规则。

## 这个案例验证了什么

CLI 能提供可核对的标签、块引用及尺寸证据，计算脚本能据此形成有公式的工作簿。本次检查了保存文件中的 56 个公式及其缓存值，确认表内没有 Excel 错误值，并核对了原图文件未改变。**尚未在 Microsoft Excel 原生引擎中打开重算验证。**

这套流程仍依赖人工确认范围、单位和图纸矛盾，以及针对本案例编写的计算脚本。CLI 没有原生 `excel` 命令，也没有承诺自动识别任意结构图并完成规范算量。

该图使用显式配置的 LibreDWG 0.14.8612 完成转换；默认固定版本 0.14 在本案例上失败。转换仍有不稳定对象诊断，不能把后续统计一致当作 DWG 整图无损的证明。
