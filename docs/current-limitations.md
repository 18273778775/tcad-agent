# 当前状态与剩余边界

CLI 的定位是图纸基础工具。房间建模和 Excel 算量展示 agent 如何使用坐标、标签、实例、尺寸与预览证据完成任务，不再把没有通用 Excel/BIM 业务命令列为功能缺项。[完整基础能力与调用方法](agent-basis.md)。

## 0.4.0 已做的改进

- **范围和复用：** 新增 workset，支持相关多页、多范围并集与去重，统一供查询、测量、面积、关联、轴网和渲染使用。工作集后续调用不再解码原整图；同一只读请求也复用第一次读取的源文档。单页可继续用 bbox 框选，全部相关页可一次生成 SVG/PNG/HTML。见 [worksets.py](../src/agentcad/worksets.py)、[protocol.py](../src/agentcad/protocol.py) 和 [io.py](../src/agentcad/io.py)。
- **SVG：** 修复底层 SVG 后端未绘制图片的问题，支持安全的本地图片嵌入和范围裁切，并打通 PNG/分图缩略图；新增字体目录、字体映射、选区质量报告和拒绝不完整输出的严格模式。见 [render.py](../src/agentcad/render.py)、[render_assets.py](../src/agentcad/render_assets.py)。
- **关联与轴网：** 支持 MLEADER、多段线引线的显式参与、竞争候选与距离差；直轴支持旋转 LINE 和共线开多段线，交点及保存后的点/范围查询按实际方向计算。几何证据与业务解释分开。见 [semantics.py](../src/agentcad/semantics.py)。

## 仍需留意的边界

1. **整图准备仍有成本。** 工作集需要先解析并导出一次；后续仍解码子图。直接对原整图调用测量、渲染等命令仍会解析原图。首次几何查询可能为全部匹配实体准备记录，输出小不等于计算量小。已有时间、内存和输出预算，性能应按具体工作流评估。[实测范围](large-drawing-performance.md)。
2. **DWG 兼容性取决于转换器。** 默认 LibreDWG 0.14 未能读通承台案例，案例显式使用 0.14.8612；转换成功仍不证明全部 DWG 对象无损。当前编辑输出为 DXF。[案例依据](cases/takeoff.md)。
3. **图框与图名依赖规则。** 自动发现针对轴对齐矩形；斜放、缺边、纸空间视口和多标题仍需配置或复核。楼号、图类元数据只保留文字规则证据，不能当作通用构件识别。[分图说明](sheet-workflow.md)。
4. **范围不是几何裁切。** bbox 选中相交实体，跨框实体完整保留；测量返回完整实体的量。未知或部分边界可能导致空间选择不完整，工作集明确报告。图纸单位为 unitless 时不会自动假定毫米。
5. **资源缺失不能靠渲染恢复。** 本地图片和可用字体可以补齐，但缺失 SHX、bigfont 组合、特殊符号及未解析 xref 仍可能改变显示。自适应填充也可能简化。质量报告不构成原 CAD 像素等价证明；严格模式用于阻止不完整结果被当作完整结果。[显示与资源](agent-basis.md)。
6. **测量仍有支持范围。** `measure` 不直接把 INSERT 块当完整构件；部分曲线面积需要离散化，未提供可认证的面积误差上界。无效、自交面积会拒绝，实体面积之和也不等于去重后的并集。[几何契约](agent-usage.md)。
7. **几何关联仍会歧义。** MLEADER 的原生引用与指定图层上的折线端点证据有不同强度。多个候选、近似距离、折线方向假设仍需 agent 结合图名、图层和 SVG 解释；不会把最近目标自动认定为工程语义正确。
8. **轴网当前限于直轴。** 已支持旋转直轴，但弧轴、弯折和其他非共线路径尚未支持，返回明确诊断。交点只基于受支持的有限几何范围，不推断不存在的延长线交点。

Windows 解释器误选已修复。pip 安装器接受 CPython 3.11–3.14，CI 覆盖 3.11–3.13；尚未发布 PyPI 包或独立免 Python 安装包。[安装说明](installation.md)。
