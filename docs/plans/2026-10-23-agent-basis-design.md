# 图纸基础能力：范围、工作集与显示证据

目标是让 agent 按任务取证、组合工具。CLI 负责图纸选择、原生实体与几何、文字和标注证据、可检查的预览；Excel 计算、业务判断和三维建模是这些基础能力的使用案例。

## 选择和解析

保留整图调用，增加显式的 `workset` 准备步骤。工作集可由一个图幅、多个相关图幅、多个 WCS 范围或整图构成，多个范围按并集选原生实体并去重，类型、图层、handle 筛选再取交集。图幅分类只使用 manifest 的文字证据和用户筛选，不凭空推断构件类别。

工作集保存较小的 DXF 和来源清单。后续 `info/query/index/measure/export/render/area/associate/axes --workset ...` 只解析该子图；核对原始来源时只校验文件摘要。来源或子图变化必须拒绝复用。handle 属于实际读取的子图，原图到子图的映射保存在清单。

这比长期持有整图进程更适合现有逐请求监督机制：工作集可跨进程复用，超时和内存隔离继续生效。单次只读请求内再复用第一次读取的同一源文档，避免索引、发现、测量或渲染在一个请求内重复解码。该缓存不跨请求，不用于编辑，不缓存 52 张验证用的导出文档。

单图幅与局部 bbox 可以组合，表示在已选图幅内进一步框选。范围只表示保守包围框相交选择；跨边界实体完整保留，测量仍返回该实体的完整几何，不能冒充精确裁切长度。

## SVG

支持显式本地图片资源目录、字体目录与字体映射。可解码图片以自包含形式嵌入，受资源与输出预算限制；不自动下载外部 URL。图层和范围选择后，单独报告实际选中内容的缺图、缺字、不支持实体及填充简化。

新增预览完整性结果和严格模式。严格模式在必要内容缺失时不发布输出。现有缺失图片与字体不能凭代码恢复，必须由调用方提供资源；CLI 应给出足以定位和补齐它们的证据。

## 关联和轴网

关联扩展到原生 MLEADER 和显式指定引线图层上的多段线，保留文字锚点、引线端点、目标与候选距离证据。竞争候选和接近的距离保留为歧义，候选生成与输出有预算。

轴网支持旋转的直轴和可靠的直线多段线，交点及点/范围查询按真实方向计算；弧轴若尚未支持，应显式记录。CLI 提供几何关系与证据，不把唯一几何匹配解释成业务语义正确。

## 验证

自动化测试覆盖范围交集、多范围并集、去重、来源变更、输出保护、实际解析次数、资源嵌入与缺失、严格模式、旋转轴和引线歧义。使用既有私有结构图复验相关图工作集及柱图；原始文件不改动、不公开。性能报告区分准备耗时、后续命令端到端耗时、原图与子图解析次数。
